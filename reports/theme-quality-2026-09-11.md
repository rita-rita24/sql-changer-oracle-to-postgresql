# テーマ切り替え・操作品質の検証

2026-09-11。対象はルートの `index.html`。

## 変更内容

- 右上に48×48pxの日食スイッチを配置。指定されたリング・軌道上の点・太陽と影のアニメーションを縮小して実装。
- ライト／ダークで背景、構文色、警告、選択色、フォーカス表示を統一。
- 初回はOSのテーマへ追従。手動選択を `sql-changer-theme` に保存し、別タブの変更にも追従。保存が使えない環境でも切り替えを継続。
- 初回描画前にテーマを適用。キーボードによるスイッチ操作と動きを減らす設定に対応。
- 空欄時の案内とサンプル、使用できない操作の無効化、入力行数表示を追加。
- クリアしたSQLを、新しく入力するまでタブ内のメモリーから復元可能にした。
- Esc→Tabで次の操作へ移動でき、出力と確認事項もキーボードでスクロール可能にした。
- 確認事項の件数を、文ごとに表示する一覧の件数と揃えた。
- マッチ候補がない置換処理の走査と、値が変わっていない入力イベントの再変換を省略。

## 検証結果

| 対象 | 結果 |
| --- | --- |
| 単体テスト | 99件成功、失敗・スキップ0件 |
| Chromium / Firefox / WebKit | 各34件、計102件成功 |
| HTML検査・全スクリプトの構文検査 | 成功 |
| 限定した変異テスト | 6/6件の意図的な不具合を検出 |
| 既存SQLの出力比較 | 179ケースに含まれる191入力のSQL・警告・診断情報・ステータスが変更前と完全一致 |
| 長文の出力比較 | 6,500文・394,279文字の出力と診断情報も変更前と完全一致 |
| 変換時間 | 上記入力のNode.js計測で2,906ms→753ms。環境・入力によって変動する |
| 画面サイズ | 320×480から1280×800まで既存10サイズ、両テーマの小画面、デスクトップの空欄・入力状態を確認 |
| 構文色 | 実際の6種の構文色をエディター背景と比較。ライトで最小5.48:1、ダークで最小7.69:1 |
| オフライン | 単独HTMLを開いて変換でき、外部リクエストと実行時エラーがないことを3ブラウザーで確認 |

入力イベントの重複試験では、100行の長いコメントを含む同じSQLが繰り返し通知されても変換は1回だけ実行され、クリア→復元→再編集後も正常に変換することを確認した。

今回のSQL比較は変換器の出力照合であり、実DBの再実行ではない。既存の変換方針と制約は `CONVERSION_POLICY.md` に記載。配布用の `dist/` とZIPは従来版のまま。この変更を配布版に含める際は、README記載の `npm run release` によるDB比較を含む検証を実行する。
